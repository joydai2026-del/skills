# Agent Skills

A small collection of agent skills for teaching, reviewing, and maintaining software work.
Each skill is a folder containing a `SKILL.md` (YAML frontmatter plus instructions) and any
reference files it needs.

Everything here is generic. These are public copies: each one teaches a method and carries no
product, client, project, or machine it was learned on. Where a skill needs a location specific
to your setup, it uses an angle-bracket placeholder such as `<HOME>` or `<NOTES_ROOT>`; substitute
your own path.

This README is generated by the skills-library export job. Edit the generator, not this file.

## Install

Each folder is a standalone skill. Install one with:

```bash
npx skills add joydai2026-del/skills/<name>
```

## What "the house rule" means

Several skills defer to "the house rule" or to "your own house rules". That is deliberate and it is not a missing link. It means the standing rules your own agent already loads (the config file, the contributing guide, or the team convention you work to), whichever that is for you. Each skill states what the rule has to SAY at that point, so you can satisfy it from your own setup without needing anyone else's rulebook.
